# skills/

One directory per skill package, grouped by category (Home, Family, Info,
Fun, Media, Robot body, Health, Learning, Utilities). A skill is plain
instructions only (a `SKILL.md` body, Claude-format-compatible) - no
permissions, no recipe. See
[docs/PACKAGES.md](https://github.com/getmaipai/.github/blob/main/docs/PACKAGES.md)
in `.github` for the manifest format. Empty until the first package lands;
see `../docs/dev.md` for the step-0 status.
